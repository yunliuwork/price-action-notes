# price-action-notes

价格行为（Price Action）趋势分析学习笔记 —— 一套中文整理笔记，共 26 章。

## 在线阅读

启用 GitHub Pages 后访问：

```
https://yunliuwork.github.io/price-action-notes/
```

## 本地阅读

直接双击 `index.html` 即可，无需服务器、无需联网。所有样式、示意图和自测题都内嵌在 HTML 中。

也可以启动一个本地服务器（可选）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

## 目录结构

```
index.html                 总目录（从这里开始）
disclaimer.html            免责声明与版权说明
price_action_chapter1_notes.html   ... 第 26 章
.nojekyll                  告知 GitHub Pages 跳过 Jekyll 处理
```

## 内容说明

- 共 26 章，按四篇组织：价格行为 / 趋势线与通道 / 趋势 / 常见趋势形态
- 每章包含：一页总览、自绘 SVG 示意图、对照表、操作流程、5 道自测题、看盘检查清单
- 全书共 130 道自测题，可点击判分

## 性质与免责声明

本笔记的内容框架来源于阿尔·布鲁克斯（Al Brooks）的价格行为交易著作。本项目是**个人学习整理与重新表述**，不是原文转录，也不是逐页摘要；所有示意图均为自绘的简化结构图，非原书插图。

**本笔记仅用于学习与研究，不构成任何投资建议。** 如需系统学习，请购买并阅读原著。

详见 [`disclaimer.html`](disclaimer.html)。

## 技术说明

纯静态 HTML + 内联 CSS/SVG/JavaScript，无构建步骤、无外部依赖。打印样式已优化，可直接用浏览器「打印 → 另存为 PDF」导出单章。
